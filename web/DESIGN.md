# 界面设计

工作台只有一个项目对话窗口。项目切换与文件夹选择在侧栏，全局资料在侧栏右侧面板管理；项目附件、CAD 边界确认、思考强度、上下文占比与灯具候选都在同一个对话上下文中，不再为业务能力拆分页面。模型缓存默认开启，但不在对话中显示状态。

CAD 上传后在会话上方显示候选轮廓与面积，用户确认后才将面积写入项目。灯具检索由对话工具调用，候选保存在项目内并在会话中提供显式“发送到 DIALux”按钮；它只触发本机导入，不显示仿真通过状态。

会话历史按项目隔离；附件在发送前可选项目资料或公共规范，回答引用检索原文与位置。界面使用中性白、深灰绿和少量绿色操作色，不使用装饰性图形代替图纸或产品图。
