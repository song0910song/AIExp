# 界面设计

工作台只有一个项目对话窗口。项目切换与文件夹选择在侧栏，全局资料在侧栏右侧面板管理；项目附件、CAD 边界确认、思考强度、上下文占比与灯具候选都在同一个对话上下文中，不再为业务能力拆分页面。模型缓存默认开启，但不在对话中显示状态。

CAD 上传后在会话内显示可折叠的多房间核对面板：原图 WCS 几何叠加、逐房间选择、尺度校准、顶点拖动/坐标编辑、手绘遗漏房间、构件补录和异常定位。分别显示文件读取状态与设计信息完整性，不把缺失高度或材料自动补成事实。

规范与规则同样在会话内以折叠面板管理：逐页证据 → 标准登记 → 候选及人工补录 → 适用性/评价场景/计算条件确认 → 规则版本绑定。来源原文不可改写，不同评价场景分组，工作面与眩光对象分开映射；待核实、冲突与失效状态持续可见。公共资料侧栏也使用逐页证据视图。

灯具检索由对话工具调用，候选保存在项目内并在会话中提供显式“发送到 DIALux”按钮；它只触发本机导入，不显示仿真通过状态。

会话历史按项目隔离；附件在发送前可选项目资料或公共规范，回答引用检索原文与位置。界面使用中性白、深灰绿和少量绿色操作色，不使用装饰性图形代替图纸或产品图。
