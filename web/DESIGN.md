# 界面设计

工作台是面向照明设计任务编排的项目对话。项目切换在左侧栏；中心对话保持连续时间顺序；图纸范围、规范资料和灯具候选在右侧项目工作区中分标签按需查看，不把可折叠状态面板固定在聊天消息顶端。

CAD 上传后由视觉模型识别图面并在助手消息中逐步给出空间用途、尺寸、门窗家具及设计影响；右侧图纸工作区仅显示原图叠加、面向业主的房间列表和纳入/排除选择。不显示 CAD 内部层名/实体 ID，不要求手填坐标、网格或反射率；缺乏可靠依据的阻塞决定以对话内表格预填推荐答案后请用户确认。

规范与规则在右侧项目工作区逐页管理：原文证据 → 标准版本 → 候选与人工复核 → 适用性/评价场景/条件绑定。中心对话按设计阶段引用来源；原文、未完成 OCR、冲突与失效状态只在用户需要查看时打开，不占据对话流顶部。

灯具检索由对话工具调用，候选保存在项目内并在会话中提供显式“发送到 DIALux”按钮；它只触发本机导入，不显示仿真通过状态。

会话历史按项目隔离；附件在发送前可选项目资料或公共规范，回答引用检索原文与位置。界面使用中性白、深灰绿和少量绿色操作色，不使用装饰性图形代替图纸或产品图。
