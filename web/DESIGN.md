# 照明设计工作台：界面设计说明

本界面服务于需要反复核对空间条件、规范证据、计算结果和真实灯具数据的照明设计人员，而不是用于展示产品卖点。因此第一屏就是可工作的项目台，不设置营销式 Hero，不编造统计数字，不用装饰图片占据主要空间。默认使用桌面端作为主工作场景，同时保证 390px 宽度下仍可完成项目切换、资料检索、计算、灯具筛选和聊天。

视觉方向采用「日光实验室」：高明度中性纸张背景代表图纸与报告，近黑绿色导航代表工程仪器外壳，暖黄色仅用于正在工作的光源、主操作和状态焦点。界面不使用渐变、悬浮大圆角卡片或紫色科技主题；信息通过细分隔线、表格、字段分组和稳定的数字列宽组织。标题使用 Bahnschrift 的窄体工业感，中文正文使用 Microsoft YaHei/Aptos，数值使用等宽字体，以保证照度、功率和版本号可快速比较。

核心流程包含七个等权工作区：项目总览、设计任务书、规范资料、预计算与规则校核、DIALux 灯具、交付文件、连续聊天。左侧导航同时显示各工作区当前记录数量；顶部始终显示当前项目、revision、RAG 后端和 LLM 可用状态。任何会修改项目的操作都携带 expected_revision，出现冲突时要求重新加载，不在前端悄悄覆盖。

图片只在 DIALux 返回真实产品图片时出现，因为这里的图片是选型证据，不是装饰。没有真实图片时显示明确的“产品图未提供”占位；不以 CSS 或 SVG 伪造灯具外观。报告和任务包由 Python 确定性服务生成，前端仅触发并下载。聊天区保留会话历史，但明确项目事实仍以 ProjectState 为准。所有空状态都说明下一项可执行操作，不填充虚构数据。
