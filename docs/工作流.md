# 照明设计工作流

仅文字说明的新建项目先完成必要参数确认、初算和灯具选型；随后只用文字询问缺失文件，不生成上传问询表格或卡片。已上传两类文件的项目直接分析并进入存量重设计，无需先保存最终选型或生成 DIALux 任务包。

```mermaid
flowchart TD
    A([用户提出需求]) --> B[创建或读取项目及已上传资料]
    B --> C{DXF 平面图和 DIALux PDF 是否齐全}
    C -->|否| C2{是否已完成灯具选型}
    C2 -->|否| S1[补全必要参数、流明法初算和灯具选型]
    C2 -->|是| S2
    S1 --> S2[纯文字询问缺失的文件]
    S2 --> S3[用户补传文件]
    S3 --> C
    C -->|是| R1[解析 DXF 与 DIALux PDF]
    R1 --> R2[提取房间轮廓、点位、评价网格、产品、安装高度和目标]
    R2 --> R3[交叉校验并披露冲突]
    R3 --> R4{是否允许调整点位或高度}
    R4 -->|允许| R5[自由重排]
    R4 -->|不允许| R6[原位替换]
    R5 --> R7[真实 IES/LDT 配光逐点评估与校准]
    R6 --> R7
    R7 --> R8{平均照度 Em}
    R8 -->|低于目标| R9[更换候选、提高功率或增加数量]
    R8 -->|高于目标 120%| R10[降低功率或减少数量]
    R9 --> R11{是否达到三轮上限}
    R10 --> R11
    R11 -->|否| R7
    R11 -->|是| R12[保存当前最优结果并标注未收敛风险]
    R8 -->|目标至目标 120%| R13[确定推荐方案]
    R12 --> O[保存 DesignRun 和重设计成果]
    R13 --> O
    O --> V[在 DIALux evo 中最终复算]
    V --> Z([结束])
```

补传只询问尚缺文件，已完成的选型无需重复。普通 PDF 不替代 DIALux 设计报告；DWG 需补传 DXF；多份不同报告由用户文字确认采用哪份。存量 PDF 作为现状和校准依据，不代表新方案已经通过最终仿真。
